# NyxFc_Website

Sito vetrina per la squadra di calcio a 7 **Nyx FC**, realizzato con PHP, CSS e JavaScript.

## Avvio in locale (PHP)

Dalla root del progetto:

```bash
php -S localhost:8000
```

Poi apri `http://localhost:8000` nel browser.

## Area admin

Per gestire le giornate vai su:

- `http://localhost:8000/admin.php`

Le giornate salvate nell'admin vengono visualizzate nella home page.

## Avvio con Docker

Dalla root del progetto:

```bash
docker compose up --build
```

Poi apri `http://localhost:8000`.
